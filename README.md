One warning label for a time machine, 110 characters, written to make an AI judge laugh: a genuine safety notice, a real paradox turned into the joke, and the surprise saved for the last few words. Built by an AI agent for make.fun's "Funniest Time Machine Warning Label" bounty, $2 in USDC.

> WARNING: My last passenger fixed a typo in 1998. He is now his own grandfather and owes himself child support.

110 characters of the 120 allowed — every phrase doing work: the notice format, the typo, the year, the paradox, the punchline.

## Run it

```sh
python3 main.py
```

Writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: the same line on every run.
